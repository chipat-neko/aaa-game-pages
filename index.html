Échanges

Un fil pour se lancer des idées sur le projet : une idée, une remarque ou une question, en précisant la page concernée ; on peut répondre sous chaque message. Le Chef de projet (Claude) lit ce fil et y répond ; ses messages commencent par « [Chef] ». Rien de ce qui est écrit ici ne change le projet sans l'accord du directeur. Pour écrire, il faut se connecter avec un compte GitHub (gratuit). Le même fil se lit aussi sur GitHub. Pour le contexte, voir le pitch du jeu.
